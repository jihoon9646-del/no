# OPR 업체 자료 자동 점검 키트

업체 메일의 첨부(엑셀/CSV)를 자동으로 저장하고, 상품코드 필수 항목(상품코드·색상·사이즈·개수) 누락을 점검해 **본인에게** 결과와 업체 보완 요청 초안을 메일로 보내는 자동화입니다. 업체에게는 아무것도 자동으로 보내지 않습니다.

## 가장 빠른 방법 (약 30~40분)
1. 이 폴더를 회사 PC에 내려받습니다.
2. Claude 데스크톱 앱 새 작업에 `3_설정도우미_프롬프트.txt` 내용을 붙여넣습니다.
3. Claude가 한 단계씩 안내합니다. 화면 캡처를 올리면서 따라가면 됩니다.

## 들어 있는 파일
| 파일 | 용도 |
|---|---|
| 1_스킬_opr-vendor-file-check.skill | 점검 규칙. Claude 설정 > Capabilities(Skills)에서 업로드 |
| 2_PowerAutomate_파일이름_식.txt | Power Automate "Create file"의 파일 이름 식 |
| 3_설정도우미_프롬프트.txt | 데스크톱 앱에 붙여넣으면 설정을 단계별로 안내 |
| 4_IT요청메일_선택.txt | PC 없이 클라우드로 돌리고 싶을 때만 (선택) |
| 5_테스트용_가상자료.xlsx | 테스트용. 점검하면 "문제 5건"이 나와야 정상 |

## 필요한 것
- 회사 도메인에 가입된 회사 PC (InPrivate 창·개인 PC에서는 회사 보안 정책으로 Power Automate 로그인이 막힘)
- Claude 회사 조직 멤버 + Claude 데스크톱 앱 + noa 커넥터 연결
- OneDrive 앱 동기화

## 설정은 고칠 필요 없음
결과 메일은 스킬을 실행한 사람 본인에게 자동으로 갑니다(noa로 본인 주소 확인). 팀 공용 주소로 받거나 필수 항목·업체 열 이름을 바꾸려면 스킬의 `config.json`을 고치거나, Claude에게 "opr-vendor-file-check 스킬의 필수 항목에 ○○ 추가해줘"라고 요청하세요.

## 알아둘 제약
- PC가 켜져 있고 데스크톱 앱이 실행 중일 때만 예약 점검이 돕니다.
- 회사 문서보안(DRM)이 걸린 파일은 "열 수 없음"으로 보고만 하고 해제하지 않습니다.
- 자세한 화면별 설명과 오류 해결은 설정 가이드 문서를 참고하세요.
